# 我是德区垃圾王

玩家扮演住在德国富人区的留学生，每天面对厨余垃圾、包装垃圾、可回收垃圾和其他垃圾的累积压力，在有限行动次数内处理垃圾、捡瓶子、换押金，并攒钱解锁稳定的垃圾处理自由。

## 如何运行

1. 打开项目目录。
2. 直接双击 `index.html`。
3. 在浏览器中选择“简单模式”或“困难模式”开始游戏。

游戏进度会自动保存到浏览器 `localStorage`。同一浏览器中可以使用“继续游戏”读取存档，或使用“重置游戏”清除存档。

## 文件结构

```text
trashqueen/
├── index.html   # 页面结构、状态区、行动区、日志区和弹窗容器
├── style.css    # 响应式布局、垃圾卡片、按钮、弹窗和指针小游戏样式
├── game.js      # 游戏配置、状态、随机事件、行动逻辑、存档和渲染
└── README.md    # 项目说明
```

## 当前已实现功能

- 简单 / 困难两种模式。
- 四类垃圾：厨余垃圾 Bioabfall、包装垃圾 Verpackung、可回收垃圾 Recycling、其他垃圾 Restmüll。
- 每日垃圾生成：基础值 + 随机浮动 + 当日事件修正。
- 0-3 个随机日常事件，包括外食、朋友来访、大餐、外卖、邻居警惕、下雨、附近活动、房间整理、节俭日、楼管巡查、搬家、考试周、兼职小费、跳蚤市场、邻居出差、Sperrmüll 日等。
- 每天有概率出现“今日奇遇”，可选择是否消耗行动尝试，结果会随机影响金钱、瓶子、楼内安全额度、风险或垃圾量。
- 家中垃圾容量、存放天数、超限罚款、连续超限失败判定。
- 每日有限行动次数。
- 楼内垃圾桶：每日安全额度，超量有被发现和罚款风险。
- 外面垃圾桶：随机出现、随机可接受类型、随机容量、随机基础风险。
- 外面垃圾桶有概率触发动态指针小游戏；未触发时用静态观察机会判定，减少重复动画。
- 散步捡瓶子有概率触发 9 格翻找小游戏；未触发时会随机走一条路线直接结算。
- 在家整理压缩有概率触发“三手整理挑战”；未触发时保留原来的直接压缩。
- 散步捡瓶子、外出顺手捡瓶子、去超市换押金，瓶子库存有上限，满了就需要先去超市处理。
- 外出或散步时有机会翻到硬币、纸币、二手书、小家具、台灯等物品并换成现金。
- 在家整理压缩垃圾，减少重量并降低存放天数。
- 用钱解锁各类垃圾处理自由，解锁后该类垃圾自动清空。
- 胜利条件：解锁全部四类，或坚持 90 天并至少解锁 2 类。
- 失败条件：金钱低于 -30 欧元，连续 3 天超限，或罚款次数达到 14 次。
- 事件日志最多保留最近 80 条。
- `localStorage` 自动保存和继续游戏。
- 电脑和手机浏览器的响应式布局。

## 参数在哪里调整

主要平衡参数都在 `game.js` 顶部的 `GAME_CONFIG` 中：

- `modes`：模式行动次数、初始金钱、楼内安全额度、罚款区间、外面垃圾桶出现概率、容量倍率、解锁价格倍率。
- `garbageTypes`：四类垃圾的每日基础产生量、浮动范围、最大容量、最大存放天数、解锁价格。
- `bottleTypes`、`maxBottles`、`bottleRoutes`、`bottleGameChance`：瓶子类型、押金金额、库存上限、直接结算路线和翻找小游戏出现概率。
- `pointerGameChance`：外面垃圾桶动态指针小游戏出现概率。
- `compressGameChance`、`compressPieces`：整理垃圾小游戏出现概率和整理项效果。
- `winDay`、`maxLogs`、`maxFineCount`：通关天数、日志长度和罚款失败线。

随机日常事件在 `game.js` 的 `DAILY_EVENTS` 中调整。今日奇遇在 `GAME_CONFIG.opportunities` 中调整。外出翻到值钱物品的概率和收益在 `GAME_CONFIG.streetFindChances` 与 `GAME_CONFIG.streetFinds` 中调整。
